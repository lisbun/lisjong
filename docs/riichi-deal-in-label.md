# 単独リーチ者に対する放銃確率推定器 — 定義（S1）

lisbun/lisjong#237（親: lisbun/lisjong-project#84 R1800ロードマップ、H/L共通部品 S1）の
定義部分を記録する。推定器本体・データ生成・評価は後続で扱い、本書が現時点の正本である。

## 位置付け

他家1人がリーチしている局面で、自分の打牌候補ごとに「その牌でリーチ者に放銃する確率」を
推定する部品。H2（価値に応じた押し引き）と学習トラックの入力・補助タスクで使う予定で、
現時点ではどのPolicyにも組み込んでいない。

推定精度、判断の質、強さは別々の主張として扱う。

## 対象局面

- 他家の**単独**リーチ（リーチ成立後）
- 対象外: 複数リーチ、リーチしていない聴牌者（ダマ・副露）

## 推定器の入力

- そのプレイヤーが判断時点で観測できる情報に限る。**自分の手牌を含む**
- 他家の手牌、山、王牌などの隠し情報は入力に使わない

## ラベル

主対象はラベルA、ラベルBは検証用の補助とする。

### ラベルA（ロン可能性）

判断時点で、リーチ者がその牌種でロンできるか。実装は
`lisjong.belief.riichi_ron_label.riichi_ron_label()`。

```text
ron_tile_types = wait_tile_types   if not furiten
               = ∅                 if furiten
```

| 要素 | 定義 |
|---|---|
| 構造的な待ち | 既存の `exact_wait_ground_truth.exact_hand_belief_with_waits()` で `wait_probability > 0` の牌種。待ちの判定は再実装しない |
| 役 | リーチ者はリーチ役を持つため、役なしは生じない |
| 捨て牌フリテン | リーチ者自身のこの局の捨て牌（鳴かれた牌を含む）に待ちの牌種があれば、すべての待ちでロンできない |
| リーチ後の見逃しフリテン | リーチ宣言打牌より後に、和了できた牌（他家の打牌・加槓牌・自摸牌）を和了しなかった場合、以後すべての待ちでロンできない |
| 赤5 | 牌種（`TileType`）で判定し、赤と通常を区別しない |

- 見逃した牌の特定（`passed_tile_types`）は、ラベルを作るデータ経路の責務とする
- リーチ者の手牌に待ちがない入力は、データ不整合として `ValueError` にする

### ラベルB（実際のロン）

その牌を実際に切ったときにロンされたか。選んだ打牌についてしか観測できないため、
ラベルAの検証にだけ使う。対局結果から求め、ラベルAの関数では扱わない。

## 情報境界

- ラベルA/Bはtraining-only truthであり、推定器・Policyの推論入力へ渡さない
- 推論時の入力に隠し情報が入らないことは、推定器を実装する段階でtestで固定する
